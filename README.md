# Frontend Development Portfolio: Forms and UI Layouts
This repository contains two projects demonstrating a balance of logical data handling and responsive design.

# Project 1: Job Application Form
What it is: A comprehensive job application form built with Bootstrap 5. It uses JavaScript to capture user input and display it in a dynamic table on the same page.
Category: Functional/Logic. This project demonstrates proficiency in handling form data, manipulating the Document Object Model (DOM), and using JavaScript arrays to manage state.

# Project 2: Ableton UI Clone (About Page)
What it is: A recreation of the About page header for Ableton. It uses advanced Bootstrap grid techniques and CSS Media Queries for responsiveness.
Category: Design/CSS. This project showcases the ability to replicate professional layouts and implement responsive design.

Mobile vs. Desktop functionality:

Desktop: Features large, high-impact typography (180px) and a multi-column navigation layout.
Mobile: Automatically scales typography down to 40px–80px using media queries to maintain readability and collapses the navigation into a streamlined menu format to fit smaller screens.

# Technical Skills Demonstrated
HTML5 and CSS3: Semantic structure and custom styling.
Bootstrap 5: Grid system, utility classes, and responsive components.
JavaScript: Event listeners, form preventDefault, and template literals for dynamic UI updates.
Responsive Design: Using media queries for fluid typography and layout shifts.
